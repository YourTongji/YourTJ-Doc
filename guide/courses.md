# 课程与排课

课程目录和排课器共用一套课程数据，但解决两个不同问题：

- 课程目录：查课程、教师、教学班和课评。
- 排课器：维护你自己的选课方案。

“我的校园”里的官方课表则来自学校接口，是只读数据，不会覆盖排课器。

## 查课程

课程页支持按课程名、课程代码、教师、学期、校区和院系筛选。

打开课程详情后，可以查看：

- 教师和教学班。
- 评分分布。
- 课评。
- 相关课程信息。

登录后可以收藏课程。

## 课评

课评支持发布、修改、删除、有用 / 无用反馈和举报。

公开页面不会显示作者身份。普通课程审核也不会直接获得作者信息；需要处理治理问题时，具备更高权限的管理员才能执行受审计的身份揭示。

::: info
课评正文当前不进入全文搜索。课程搜索用于发现课程和教学班。
:::

## 使用排课器

进入 `/schedule`，选择学期和专业后即可添加课程。

支持：

- 多套方案。
- 周次和单双周。
- 时间冲突提示。
- 自定义占位。
- 方案比较。
- PNG / CSV 导出。

时间冲突不会阻止加课。系统把冲突标出来，由你决定保留哪一种安排。

## 云同步

未登录时，方案保存在本地。登录后可以同步到 YourTJ 账号。

服务端会记录方案版本。假设两台设备都从同一个版本开始编辑：

```text
设备 A 保存成功 -> 云端产生新版本
设备 B 仍拿旧版本保存 -> 返回冲突
```

设备 B 会先重新读取云端，再处理自己的本地修改；旧快照不会覆盖 A 已写入的新数据。

Web 会保留从未同步或尚未上传的本地修改；发生冲突时可生成本地恢复方案。

::: warning
排课同步解决的是 YourTJ 多设备方案一致性，不会向学校教务系统提交选课。
:::
