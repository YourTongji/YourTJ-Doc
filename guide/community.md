# 社区

YourTJ 社区使用“话题 + 楼层回复”的结构。发布时选择内容类型，后续回复、收藏、通知和审核都围绕同一个话题工作。

## 选择内容类型

| 类型 | 适合 |
| --- | --- |
| 瞬间 | 短内容、图片、日常记录 |
| 提问 | 围绕一个明确问题讨论 |
| 文章 | 长内容、经验整理 |

瞬间会保留完整话题页，可以持续回复和查看。

## 发布和草稿

快捷发布适合瞬间和短内容；提问、文章或需要完整 Markdown 编辑时使用完整发布页。

只要编辑器里已经有正文、分类或图片，离开时会提示是否保存。这里有两种不同的“保存”：

- **本地恢复**：防止刷新、误关页面导致丢稿，只服务当前浏览器。
- **服务端草稿**：进入草稿箱，适合以后继续编辑。

需要跨设备继续写时，请主动保存为服务端草稿。

## 回复视图

同一话题可以按两种方式阅读：

- **扁平**：按楼层号从前往后。
- **树状**：按真实回复关系展示上下文。

树状模式只改变阅读方式，不改变楼层本身。视图偏好保存在当前浏览器中。

## @ 提及

输入 `@username` 可以提及其他用户。

编辑器会提供候选；服务端在保存正文时识别真正的提及。代码块、链接、图片说明、数学内容等位置中的 `@` 不会被当成普通提及。

编辑旧内容时，只会对新增加的提及发送通知，避免每次保存都重复提醒同一用户。

## 点赞、收藏和通知

首页和详情页都可以进行点赞、收藏等互动。

站内通知是基础能力。浏览器通知、Web Push 和原生推送属于额外投递通道，能否收到还取决于设备权限和服务器配置。

::: tip
Chrome Web Push 依赖 FCM；部分网络环境可能无法投递。站内通知不受这一限制。
:::

## 删除内容

内容删除有恢复窗口和最终清理两个阶段。

最终清理后，内容不会再出现在普通用户读取路径，也不能由用户恢复。治理审计使用独立的保留规则，不等同于用户侧“还能找回”。
