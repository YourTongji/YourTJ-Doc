# 校园地图

校园地图入口为 `/map`，无需登录。

当前包含四平路、嘉定、沪西、沪北、张江和临港校区 / 基地。

## 找一个地点

地图支持建筑与设施搜索、分类筛选和地点详情。

常用操作：

1. 切换校区。
2. 搜索建筑名称或别名。
3. 从结果中选择地点。
4. 地图聚焦到目标并打开详情。

页面地址可以携带校区和地点参数，复制 URL 即可分享指定建筑。

## 2D / 2.5D

地图可以在平面和 2.5D 视图间切换。

建筑高度、运动场标线等仅用于导览，不作为工程测绘数据或实时场馆状态。

## 使用当前位置

点击“当前位置”后，浏览器才会请求定位权限。

定位成功时，地图会显示当前位置和精度范围；如果附近能匹配到已校准校区，也可以切换到对应校区。

YourTJ 不会：

- 持续追踪位置。
- 把坐标写入 URL。
- 把坐标写入浏览器存储。
- 把坐标上传到论坛 API。

::: info
张江当前使用未校准的本地平面图。即使浏览器获得定位，也不会把经纬度强行画到这张图上。
:::

## 地图数据

地图使用随论坛版本发布的 GeoJSON 和 MapLibre GL JS，不依赖外部地图 API token。

地图页面的基础建筑和设施数据随论坛版本发布。更新地图数据后需要重新构建站点。
